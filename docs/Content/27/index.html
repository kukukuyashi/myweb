鼠标动画光标：从 PNG 序列到 Chrome 兼容

日期：2026-06-29

一、要解决的两个问题

  1. Chrome 里 CSS 光标不动 — cursor: url(...gif) 往往只显示 GIF 第一帧。
  2. 移动时有黑色拖影 — 用 <img> + transform: translate() 跟随时，GIF 半透明黑边会在路径上残留像素。

Firefox 对 CSS GIF 光标支持较好；Chrome / Edge 需要 JS 叠加层。拖影则要用 Canvas 每帧 clearRect 再 drawImage，并用 left/top 定位（不用 transform）。

四、运行时：Canvas + PNG 精灵图

为什么不用 GIF 直接画到 Canvas？

drawImage(gifImage, …) 在浏览器里只会取 GIF 第一帧，动画会消失。

为什么不用 <img> 跟着鼠标？

transform 移动 animated GIF 容易留下黑色拖影。

最终方案：构建时把 PNG 序列横向拼成 精灵图（normal-sheet.png 等），运行时读 manifest.json，Canvas 按帧索引切图：


paintLoop → frameIndex++ → drawImage(sheet, index×64, 0, 64, 64, …)
mousemove → left/top 定位（不用 transform）

App.vue 挂载 useAnimatedCursor()；CSS 里 html.has-animated-cursor { cursor: none }。

七、踩坑

  1. Canvas + GIF → 只有第一帧，无动画。
  2. <img> + transform 移动 → 容易黑边拖影，改 left/top 或精灵图。
  3. GIF 半透明量化 → 必须清 alpha 脏边，并设 disposal=2。
  4. 路径要带 base → import.meta.env.BASE_URL + 'cursors/...'。
  5. 不要用 will-change: transform 跟鼠标 — 会加剧合成层残留。
