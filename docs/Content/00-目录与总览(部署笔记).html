CYINC.LOG 新手部署笔记 · 目录与总览

面向：懂一点 HTML/CSS/JS/Python，但从未把网站放到服务器上过的人。
目标：把本地跑通的 CYINC.LOG 整站，部署到阿里云 ECS（Ubuntu 22.04），用 Docker + Nginx + HTTPS 对外访问。

这套笔记在讲什么？

把网站上线，可以想成「搬家」：

本地（开发） 生产（服务器）
Windows + phpStudy MySQL Ubuntu ECS + MySQL（Docker 或 RDS）
npm run dev 热更新 构建后的静态文件放在 Nginx 目录
uvicorn 直接跑后端 Docker 容器里跑 FastAPI
http://localhost:5173/myweb/ https://你的域名/myweb/

本仓库的正式运维文档是 ../README-m6-ecs.md。本目录是分阶段、带命令解释的新手版，按顺序做完即可上线。

上线后的访问形态（务必先记住）

生产采用前后端同域：


https://你的域名/myweb/          →  Vue 静态站（base=/myweb/）
https://你的域名/myweb/app       →  平台 Hub
https://你的域名/api/v1/...      →  FastAPI（Nginx 反代到 127.0.0.1:8000）
https://你的域名/api/health      →  健康检查
https://你的域名/admin           →  SQLAdmin
https://你的域名/uploads/...     →  用户头像等上传文件
https://你的域名/myweb/img/...   →  大图（Nginx 直出，不打进前端包）
https://你的域名/myweb/Music/... →  音乐（同上）

服务器上的主目录约定为：


/var/www/cyinc/                 ← 仓库根目录（git clone 到这里）
├── myweb/                      ← 前端构建产物（来自 docs/）
├── img/                        ← 大图媒体
├── Music/                      ← 音乐媒体
├── backend/
│   ├── .env                    ← 生产密钥（勿提交 Git）
│   └── Dockerfile
├── docker-compose.prod.yml
└── deploy/
    └── nginx.conf.example

项目 粗略预估

上图为实拍：从提交审核到管局通过大约几天（本例约 2026-07-11 → 07-15）。通过后记得：

  1. 网站首页底部挂备案号，并链到 工信部备案查询
  2. 网站开通后 30 日内 另做公安备案（与 ICP 备案不是同一件事）

国内地域 ECS：备案通过前，可用 IP + HTTP 自测；对外正式访问建议 HTTPS + 备案完成。

安全底线（写笔记前先说清楚）

  1. 永远不要把 backend/.env、真实密码、SECRET_KEY 提交到 Git 或发到公开聊天。
  2. 安全组只开放 22 / 80 / 443；不要把 8000、3306、6379 对公网开放。
  3. 生产 SECRET_KEY 必须用随机值生成，不要用示例里的 change-me。
