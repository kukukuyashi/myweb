从 LLM 到 Agent Skill 笔记

2026-06-09 · Agent

从 LLM 到 Agent Skill 的基础概念梳理，带 💡 通俗解释，方便随时查阅。

一、底层引擎：大语言模型（LLM）

  • LLM：Large Language Model 的缩写，就是「大语言模型」，也叫「大模型」。
💡 一个特别能猜词的超级智能程序。
  • Transformer：2017 年谷歌提出的技术架构，所有现代大模型都基于它。
💡 大模型的「发动机」，让模型能看懂词语之间的顺序和关系。
  • 工作原理：本质是文字接龙。模型根据你给的文字，一个一个地猜下一个字（词）是什么，直到生成完整回答。
💡 就像手机输入法的「预测下一个词」，但比它强大一万倍。

二、数据处理单元：Token

  • Token：大模型处理文本的最小单位。不是字，也不是单词，是切分出来的片段。
    👉 大白话：模型「吃饭」时的一口食物。一口可能是一个字的一半，也可能是一个完整单词。
  • Tokenizer（分词器）：把原始文本切成 Token 的工具。
    👉 大白话：厨房里的菜刀，把句子切成一段一段。
  • Token ID：每个 Token 对应的数字编号。
    👉 大白话：每个「菜段」的标签码，模型只认这个码。

常见换算（大致）：

  • 1 个 Token ≈ 0.75 个英文单词
  • 1 个 Token ≈ 1.5~2 个汉字
  • 40 万 Token ≈ 一本超厚的小说（60~80 万字）

三、临时记忆体：Context

  • Context：模型在处理一次任务时「看到」的全部信息，包括你的问题、历史对话、刚才生成的词、系统设定等。
    👉 大白话：模型的「临时工作台」，上面摆着它当前能用的所有材料。
  • Context Window（上下文窗口）：模型一次最多能处理的 Token 数量。
    👉 大白话：工作台的最大面积。面积越大，一次能放的材料越多。
模型（示例） 窗口大小（Token） 约合汉字
GPT-4 Turbo 12.8 万 约 19 万字
Gemini 1.5 Pro 100 万 约 150 万字
Claude 3 Opus 20 万 约 30 万字
  • RAG（检索增强生成）：当问题需要的知识太多放不进窗口时，先从外部知识库里找出最相关的内容，只把这些塞给模型。
    👉 大白话：书太多桌子放不下，就先查目录，只把有用的几页放在桌上。

四、指令交互：Prompt

  • Prompt：你给大模型的指令或问题。
    👉 大白话：你对模型说的「开场白」或「命令」。
  • User Prompt：用户直接输入的内容。
    👉 大白话：「你」对模型说的话。
  • System Prompt：开发者在后台设定的「人设」和「规则」。
    👉 大白话：模型开机自带的「性格说明书」和「工作守则」。
  • Prompt Engineering（提示词工程）：研究怎么写更有效的 Prompt。
    👉 大白话：学习怎样「把话说清楚」，让模型更容易懂你。
    现状：门槛低，重要性在下降，因为模型越来越聪明。

五、外部能力扩展：Tool

  • Tool（工具）：大模型可以调用的外部函数/API，比如查天气、算数学、发邮件。
💡 给模型配的「外挂设备」。模型本来只会说话，加了工具就能动手做事。

解决痛点：

  • 大模型不知道实时信息（比如今天天气）
  • 大模型计算大数容易出错
  • 大模型不能直接操作你的电脑或手机

六、工具标准化：MCP

  • MCP：Model Context Protocol，模型上下文协议。
💡 让不同大模型（OpenAI、Google、Anthropic）都能用同一套标准来调用工具。

类比：以前每个平台都有自己的充电口（Lightning、Micro-USB、Type-C）。MCP 就像大家都统一成 Type-C 接口。你只按 MCP 标准开发一次工具，所有支持 MCP 的模型都能用。

七、自主决策系统：Agent

  • Agent：能自己规划步骤、自己决定调用哪个工具、一直工作到完成你交给它的任务的那个程序。
💡 一个「跑腿小能手」——你给它一个目标，它自己想办法、用工具、反复尝试，直到搞定。

核心能力：

  • 多维度推理（想一想先做什么后做什么）
  • 工具选择（知道该查天气还是该发邮件）
  • 流程控制（自己做判断，不用每一步都问你）

代表产品：Claude Code、Codex、Gemini CLI

典型工作模式：ReAct（思考+行动）、Plan and Execute（规划后执行）

八、任务定制：Agent Skill

  • Agent Skill：为 Agent 预先定制好的「专项技能包」，让它能更高效地完成特定任务。
💡 给 Agent 装的「APP」或「插件」。比如「Excel 处理技能」、「合同审阅技能」。

高级功能：

  • 运行代码
  • 引用本地文件
  • 渐进式微调（只更新必要的部分，节省 Token）
  • 按需检索相关知识
