日期：2026-06-26

一、自定义鼠标样式

原理

浏览器的 cursor CSS 属性支持自定义图片作为光标，语法：


cursor: url('图片路径') x y, fallback;
  • x y：光标热点坐标（点击位置相对于图片左上角的偏移）
  • fallback：备用系统光标（auto、pointer、text 等）

支持的图片格式

格式 浏览器支持 动态 推荐
.png 全部 否 静态光标
.gif 全部 是 动态光标首选
.cur 仅 IE 否 不推荐
.ani 仅 Windows 是 浏览器不支持

结论：用 .gif 做动态光标，.png 做静态兜底。

尺寸限制

浏览器对 cursor 图片有尺寸限制，推荐 32x32 或 64x64 像素。太大的图片会被浏览器忽略。

用 Python + Pillow 缩放：


from PIL import Image

img = Image.open('原始图片.gif')
img = img.resize((64, 64), Image.Resampling.LANCZOS)
img.save('输出.gif')

多帧 GIF 需要逐帧处理：


frames = []
durations = []
try:
    while True:
        frame = img.copy().resize((64, 64), Image.Resampling.LANCZOS)
        frames.append(frame.convert('RGBA'))
        durations.append(img.info.get('duration', 100))
        img.seek(img.tell() + 1)
except EOFError:
    pass

frames[0].save(
    'output.gif',
    save_all=True,
    append_images=frames[1:],
    duration=durations,
    loop=0,
)

文件放置

把光标 GIF 放到 public/cursors/ 目录下，Vite 会自动把 public/ 下的文件复制到构建输出。

CSS 实现

在 src/styles/_base.css 中添加：


/* 默认光标 */
html {
  cursor: url('/myweb/cursors/normal.gif') 8 8, auto;
}

/* 加载/路由切换时的动态光标 */
html.cursor-busy {
  cursor: url('/myweb/cursors/busy.gif') 8 8, wait;
}

/* 链接和按钮 */
a, button, [role="button"] {
  cursor: url('/myweb/cursors/pointer.gif') 8 8, pointer;
}

/* 文本输入 */
input, textarea, select {
  cursor: url('/myweb/cursors/text.gif') 8 8, text;
}
注意路径要加上项目的 base 巌（如 /myweb/），否则开发环境会 404。

路由切换时自动切换动态光标

在 useRouteTransition.js 中，路由切换时给 html 加上 cursor-busy class：


router.beforeEach(() => {
  document.documentElement.classList.add('cursor-busy')
})

router.afterEach(() => {
  setTimeout(() => {
    document.documentElement.classList.remove('cursor-busy')
  }, 300)
})

从 .ani 提取帧

如果只有 .ani 文件（Windows 动态光标），可以用 Python 解析 RIFF 容器提取帧：


import struct
from PIL import Image
import io

with open('cursor.ani', 'rb') as f:
    data = f.read()

# 跳过 RIFF + ACON 头
offset = 12
icon_chunks = []

while offset < len(data) - 8:
    chunk_id = data[offset:offset+4]
    chunk_size = struct.unpack('<I', data[offset+4:offset+8])[0]
    chunk_data = data[offset+8:offset+8+chunk_size]

    if chunk_id == b'LIST' and chunk_data[0:4] == b'fram':
        inner = 4
        while inner < len(chunk_data) - 8:
            sub_id = chunk_data[inner:inner+4]
            sub_size = struct.unpack('<I', chunk_data[inner+4:inner+8])[0]
            if sub_id == b'icon':
                icon_chunks.append(chunk_data[inner+8:inner+8+sub_size])
            inner += 8 + sub_size + (sub_size % 2)

    offset += 8 + chunk_size + (chunk_size % 2)

# 逐帧转 PNG
for i, icon_data in enumerate(icon_chunks):
    img = Image.open(io.BytesIO(icon_data))
    img = img.resize((64, 64), Image.Resampling.LANCZOS)
    img.save(f'busy_{i}.png')

二、点击涟漪效果

原理

每次点击时，在鼠标位置创建一个 <div>，用 CSS @keyframes 让它从小圆扩散到大圆，同时淡出。动画结束后自动移除 DOM。

创建 composable

新建 src/composables/useClickRipple.js：


import { onMounted, onUnmounted } from 'vue'

export function useClickRipple() {
  function createRipple(e) {
    if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) return

    const ripple = document.createElement('div')
    ripple.className = 'click-ripple'
    ripple.style.left = `${e.clientX}px`
    ripple.style.top = `${e.clientY}px`
    document.body.appendChild(ripple)

    ripple.addEventListener('animationend', () => {
      ripple.remove()
    })
  }

  onMounted(() => document.addEventListener('click', createRipple))
  onUnmounted(() => document.removeEventListener('click', createRipple))
}

CSS 动画

在 src/styles/_layout.css 中添加：


.click-ripple {
  position: fixed;
  width: 0;
  height: 0;
  border-radius: 50%;
  border: 2px solid var(--orange);
  pointer-events: none;
  z-index: 99998;
  transform: translate(-50%, -50%);
  animation: click-ripple-expand 0.6s ease-out forwards;
}

@keyframes click-ripple-expand {
  0% {
    width: 0;
    height: 0;
    opacity: 0.8;
  }
  100% {
    width: 80px;
    height: 80px;
    opacity: 0;
  }
}

在 App.vue 中启用


import { useClickRipple } from './composables/useClickRipple'
useClickRipple()

关键点

  • position: fixed + e.clientX/Y：涟漪跟随点击位置，不随页面滚动
  • pointer-events: none：涟漪不拦截后续点击
  • animationend 事件后 remove()：自动清理 DOM，不会内存泄漏
  • prefers-reduced-motion 检测：尊重用户的动画偏好设置
  • z-index: 99998：确保在最上层但不遮挡加载屏幕

三、踩坑记录

  1. 路径问题：Vite 项目的 base 配置会影响静态资源路径。如果设了 base: '/myweb/'，CSS 里的 cursor URL 要写 /myweb/cursors/... 而不是 /cursors/...
  2. 图片尺寸：浏览器对 cursor 图片有 128x128 或更小的限制，实际测试 64x64 最稳定
  3. GIF 动画：cursor 属性原生支持 GIF 动画，不需要任何 polyfill
  4. .cur/.ani 不兼容：Windows 专用格式浏览器不支持，必须转成 PNG/GIF
  5. CSS 选择器优先级：如果某个组件自己设了 cursor，会覆盖全局设置，需要用更具体的选择器或 !important

静态预览供搜索引擎阅读；交互版由 Vue 加载后替换本区域。
