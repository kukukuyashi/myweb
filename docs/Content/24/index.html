首页 Hero、音乐室、关于页顶栏都有「鼠标划过去，线稿从纸面晕开」的效果。这篇拆开 DOM 结构、Canvas 遮罩原理和 Vue 组件怎么接，方便以后换图或复用到别的面板。

首页墨染晕染：鼠标 hover 显现线稿

日期：2026-06-16
效果位置：首页 Hero、音乐室、关于 / 留言板页头

效果是什么？

默认状态下，区域像一张米色纸，右侧隐约压着一张线稿/照片。鼠标移入并滑动时，纸面被「墨晕开」，底下的图逐渐露出来；停笔后墨迹会慢慢缩回、纸面重新盖住。

不是 GIF，也不是视频 — 纯 CSS 分层 + Canvas 动态遮罩，帧率跟手走。

DOM 长什么样？

页面上你看到的 ink-panel__content（标题、统计数字等）只是最上层文字。完整结构是两件套：

<InkRevealPanel root-class="hero hero--ink" image="img/关于/FrhwkwYaMAE2R6L.jfif" ...>
  <div class="hero-coord">... hover 晕染</div>
  <h1>写给自己的技术学习日志</h1>
  ...
</InkRevealPanel>

渲染后大致等价于：

<section class="ink-panel hero hero--ink">
  <!-- 背景层：HeroInkReveal，pointer-events: none -->
  <div class="ink-reveal-layers">
    <div class="ink-reveal__bg">          <!-- 线稿图 background-image -->
      <div class="ink-reveal__fade"></div> <!-- 左侧文字保护渐变 -->
    </div>
    <canvas class="ink-reveal__mask"></canvas> <!-- 纸色遮罩，鼠标擦除 -->
  </div>
  <div class="ink-panel__content">...你的 slot 内容...</div>
</section>
组件职责
InkRevealPanel.vue面板外壳：切角边框、橙色折角、slot 内容区
HeroInkReveal.vue线稿图 + 渐变 + Canvas 墨染逻辑

三层画面怎么叠？

  1. 底层：ink-reveal__bg 用 background-image 铺线稿，background-position 控制构图（首页 85% center 把人物压在右侧）。
  2. 渐变层：ink-reveal__fade--left 从左侧 --bg-paper 过渡到透明，保证标题区始终可读，不被线稿抢戏。
  3. 遮罩层：全尺寸 canvas 涂满纸色（--bg-paper），鼠标划过时用「挖洞」把纸擦掉，露出下面已存在的线稿。

关键点：线稿一直在底下，动的是遮罩，不是换图。

Canvas 怎么「墨晕开」？

核心在合成模式 destination-out：在已有像素上画的内容会扣掉 alpha，相当于橡皮擦，但擦出来的是不规则墨团。

1. 鼠标轨迹 → 墨点队列

mouseenter / mousemove 绑在外层 panel（hero）上，Canvas 本身 pointer-events: none，避免挡点击。每次移动按步长 STAMP_STEP = 8px 插值，避免快速划过只有稀疏几个点。

每个墨点存：x, y, born（出生时间）, seed（形状随机）, rmax（最大半径）。

2. 画一团不规则墨

carveInk() 用径向渐变 + 32 段波浪圆（sin 扰动半径），边缘像墨水洇开而不是正圆：

ctx.globalCompositeOperation = 'destination-out'
carveInk(x, y, r, alpha, seed)

3. 动画：晕开再收回

每帧 requestAnimationFrame：

  • 先用纸色 fillRect 铺满 Canvas（重置遮罩）
  • 遍历所有墨点，按存活时间 t 计算半径（ease 放大）和透明度（1 - t² 淡出）
  • 超过 LIFETIME = 560ms 的墨点丢弃；没有墨点时停止 rAF，省电

所以效果是：跟手晕开 → 停笔后自动回纸，不需要额外「清除」动画。

首页怎么用？

<InkRevealPanel
  tag="section"
  root-class="hero hero--ink"
  image="img/关于/FrhwkwYaMAE2R6L.jfif"
  position="85% center"
  :r-end="128"
  :max-stamps="150"
>
  ... Hero 文案、统计 ...
</InkRevealPanel>
Prop含义
image相对站点根的图路径，走 imgUrl()
positionCSS background-position
r-end墨团最大半径（px），越大晕开范围越大
max-stamps同屏墨点上限，防极端快速划线卡顿
fade-directionleft / right，文字保护渐变方向
bleed为 true 时去掉切角边框（关于页大图用）

音乐室、留言板用 tag="header" + page-ink-header；关于页 about-hero--ink + 另一张 BA 线稿。

样式：纸感从哪来？

  • 遮罩颜色读 CSS 变量 --bg-paper，深色模式换 data-theme="dark" 时 MutationObserver 会重刷 Canvas 底色。
  • .ink-panel 带工业风切角 clip-path 和右下角橙色三角（::after）。
  • 线稿层 filter: saturate(0.88) contrast(1.05) 略压饱和，更像印刷线稿。

无障碍与触屏

  • prefers-reduced-motion: reduce：关掉 Canvas 动画，线稿以低透明度静态露出。
  • hover: none（手机）：不绑鼠标逻辑，同样静态淡出线稿；「hover 晕染」提示文字隐藏。
  • 背景层 aria-hidden="true"，不影响读屏读标题。

实现时注意的几件事

  • 事件绑在 panel 上：HeroInkReveal 里 rootRef.parentElement 才是带内容的整块 Hero，区域比 Canvas 大，边缘也能触发。
  • DPR 封顶 2：高分屏 Canvas 物理像素乘 devicePixelRatio，但最大 2，避免 4K 屏性能崩。
  • ResizeObserver：侧栏折叠、窗口缩放时重设 canvas 尺寸并重涂纸色。
  • 全局单例 Audio 无关：墨染和音乐播放器独立；切页不销毁 App.vue 外的 panel 时会 onUnmounted 卸监听。

想换一张图？

  1. 把线稿放进 img/（开发时 Vite 中间件会直接读本地 img/）。
  2. 改 InkRevealPanel 的 image 和 position，调 r-end 直到晕开范围顺眼。
  3. 文字如果在右侧，把 fade-direction 改成 right。

小结

墨染不是魔法滤镜：底图 + 纸色 Canvas + destination-out 抠洞 + 时间轴淡出。Vue 侧用 InkRevealPanel 包内容、HeroInkReveal 管画布，首页 Hero 的 ink-panel__content 只是最上层 UI。理解分层之后，换图、调晕染大小、接到别的页面都是改 props 的事。
