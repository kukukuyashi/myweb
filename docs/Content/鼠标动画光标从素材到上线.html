鼠标动画光标：从 PNG 序列到 Chrome 兼容

日期：2026-06-29

一、要解决的两个问题

  1. Chrome 里 CSS 光标不动 — cursor: url(...gif) 往往只显示 GIF 第一帧。
  2. 移动时有黑色拖影 — 用 <img> + transform: translate() 跟随时，GIF 半透明黑边会在路径上残留像素。

Firefox 对 CSS GIF 光标支持较好；Chrome / Edge 需要 JS 叠加层。拖影则要用 Canvas 每帧 clearRect 再 drawImage，并用 left/top 定位（不用 transform）。

四、运行时：useAnimatedCursor.js

核心思路：隐藏系统光标 + Canvas 跟随鼠标。


mousemove → rAF 更新 left/top
         → elementFromPoint 判断 normal / pointer / text / busy
paintLoop → 每帧 clearRect → drawImage(当前 GIF 的隐藏 Image)

四种 GIF 预加载到 HTMLImageElement，Canvas 只负责显示当前帧，不在 DOM 里移动 <img>，避免 compositor 拖影。

App.vue 挂载：


useAnimatedCursor()

CSS：html.has-animated-cursor 下全局 cursor: none；.animated-cursor 为 position: fixed 的 canvas，不设 will-change: transform。

七、踩坑

  1. <img> + transform 移动 animated GIF → 容易黑边拖影，改 Canvas + left/top。
  2. GIF 半透明量化 → 必须清 alpha 脏边，并设 disposal=2。
  3. 路径要带 base → import.meta.env.BASE_URL + 'cursors/...'。
  4. 不要用 will-change: transform 跟鼠标 — 会加剧合成层残留。
